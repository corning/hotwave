# HEARTBEAT.md — A 股交易时段自动巡检

> **机制说明：** 系统默认在 A 股交易时段（09:00-15:20）每约 10 分钟触发一次心跳，可用 `HEARTBEAT_START` / `HEARTBEAT_END` 与 `HOTWAVE_HEARTBEAT_INTERVAL_MS` 调整。你收到此文件内容时，根据**当前北京时间**判断处于哪个市场阶段，执行对应操作。

## A 股市场关键时间节点

| 时段 | 时间 | 状态 | 操作 |
|------|------|------|------|
| 盘前准备 | 09:00-09:25 | 集合竞价前 | 市场分析，不交易 |
| 集合竞价 | 09:25-09:30 | 产生开盘价 | 观察 |
| **早盘交易** | **09:30-11:30** | **连续交易** | **监控** |
| 午间休市 | 11:30-13:00 | 休市 | **运行多因子选股** |
| **午盘交易** | **13:00-15:00** | **连续交易** | **监控** |
| 收盘集合竞价 | 14:57-15:00 | 产生收盘价 | 观察 |
| **盘后复盘** | **15:00-16:00** | 闭市 | **运行多因子选股 + 复盘** |

## 根据当前时间执行对应任务

### 1. 盘前准备（09:00-09:25）

LLM 执行分析性工作，不需要调用数据工具：

- 确认今日是否为交易日（排除周末，关注节假日）
- 回顾昨日市场状态（从 `MEMORY.md` 和 `memory/` 目录读取）
- 更新当日观察清单
- 记录到 `memory/YYYY-MM-DD.md`

> 不需要调用数据工具。盘前没有新数据。

### 2. 盘中监控触发点（09:30-11:30 | 13:00-15:00）

心跳每约 10 分钟触发一次，你能看到的时间点取决于启动时刻与间隔配置。

**可执行的操作：**

- 用 `finance_kline` 查询关键个股的当日分K线（周期 5m/15m）
- 分析走势是否异常（放量/破位/突破）
- 如果用户有自选股，检查技术形态变化
- **不要尝试高频监控**——LLM 心率做不到实时策略执行

### 3. 午间休市扫描（11:30-13:00） ← 关键定时任务

**这是每个交易日最重要的定时任务。** 当心跳在 11:30-13:00 之间触发时，运行多因子选股并记录扫描结果。

将扫描结果摘要写入 `memory/YYYY-MM-DD.md`：
- 筛选出多少只股票
- 所属板块分布
- 符合条件的技术形态特征

### 4. 盘后复盘（15:00-16:00） ← 关键定时任务

**当心跳在 15:00-16:00 之间触发时（需将 HEARTBEAT_END 调整到 16:00）：**

1. 运行收盘多因子选股
2. 获取关键标的日K数据
3. 生成当日复盘总结写入 `memory/YYYY-MM-DD.md`
4. 更新 MEMORY.md 中的关键信息

### 5. 非交易时段（16:00-次日 09:00）

心跳不触发。但如果用户主动对话，回答市场相关问题、分析历史数据、准备次日交易计划。

---

## 执行原则

1. **不臆测数据——** 所有分析必须基于工具返回的真实数据
2. **不丢弃错误——** 工具调用失败时，把错误信息报告给用户
3. **写文件就是记记忆——** 所有分析结果写入 `memory/YYYY-MM-DD.md`
4. **一个心跳只做一个核心任务——** 不要在一个心跳周期内同时做选股+深度分析+K 线查询
